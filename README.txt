APEX MOTORS — CAR SHOWROOM WEBSITE
==================================

PROJECT FILES
-------------
index.html  Main website structure and car showroom content
style.css   Responsive styling and layout
script.js   Model details, category filters, comparison and test-drive form
README.txt  Setup instructions

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the Car_Showroom_Website folder.
3. Double-click index.html to open it in Chrome, Edge, Firefox or another modern browser.
4. An internet connection is recommended for Google Fonts and the remote car photographs.

FEATURES
--------
- Modern car showroom landing page
- Six sample vehicle cards with photos, prices and specifications
- Vehicle category filters (SUV, Sedan, Electric and Sport)
- Model details popup with key features
- Compare up to three cars side by side
- Test-drive request form with basic validation
- Responsive layout and mobile navigation

IMPORTANT PROJECT NOTES
-----------------------
This is a front-end educational demo. It is not an official vehicle catalogue.
All car model names, specifications, performance figures, prices and features are
illustrative sample data and must not be treated as manufacturer specifications.
The test-drive form does not send or store personal information. For a real
showroom website, connect it to a secure backend and replace sample data with
verified details from the relevant manufacturer or authorised dealer.
